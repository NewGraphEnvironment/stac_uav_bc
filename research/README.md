# research

What is known about the UAV data, kept current in place. Each file says when it was last verified,
which issues it came from, and what produced its numbers.

Naming: `<topic>.md`, revised in place, from 2026-10-16. A topic's probes, tables and figures sit in
a directory of the same name.

| file | covers |
|---|---|
| [`uav_pointclouds.md`](uav_pointclouds.md) | The ODM and Maps Made Easy point clouds: inventory, their offset from LidarBC (and so the published DTM/DSM's), one pre/post change test, and where the value is |

Related work: [stac_pointcloud_bc](https://github.com/NewGraphEnvironment/stac_pointcloud_bc) (the
LidarBC point clouds) and [stac_dem_bc](https://github.com/NewGraphEnvironment/stac_dem_bc) (the
LidarBC DEMs used as the reference here).
